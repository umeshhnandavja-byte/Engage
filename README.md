# engage

Engage is an app for managing events conducted with in an organisation

## Features
1. Event Info like description date time
2. Registration and form
3. Event attendants using an QR system
4. Live Quizes During the Event
5. Live Doubts Asking from your phone (Even Anonymously)
   and many more
